Diseñado para paranoia sana

Un único binario estático sin dependencias externas ni telemetría.

Criptografía

AES-256-GCM + Keychain nativo

Cada descargo se cifra con un nonce aleatorio antes de tocar disco. La clave maestra vive en macOS Keychain, Windows Credential Manager o Linux Secret Service.

Observabilidad

Dashboard web efímero

rant ui levanta un servidor local en un puerto aleatorio con token de sesión en memoria, heatmap estilo GitHub y Modo Censura para compartir pantalla.

Cero Rastro

Sin historial ni botón de pánico

Incluye shell-init para excluir comandos del historial de shell y rant nuke para sobreescribir la base SQLite y destruir la clave maestra.

Referencia rápida

Todo lo que necesitás desde la línea de comandos.

rant "mensaje" -t tag1,tag2 -s 4 Registra un descargo rápido con etiquetas y severidad (1 a 5).
rant Sin argumentos abre tu $EDITOR para escribir descargos largos sin pasar por ps aux.
rant list Descifra y lista en consola todos los descargos guardados en la bóveda.
rant retro --days 30 Muestra estadísticas de impacto por día, hora y tags sin exponer texto crudo.
rant ui Abre la visualización local en el navegador y se apaga al cerrar la pestaña.
rant nuke Sobreescribe el archivo SQLite y elimina la clave maestra del sistema operativo.
